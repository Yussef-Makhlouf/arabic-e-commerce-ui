## 🔐 Authentication System

The project implements a full-stack custom authentication system without external providers (like Auth0 or NextAuth) to demonstrate core concepts.

### 1. Backend Logic (`lib/user-service.ts`)
*   **Storage**: Users are stored in a local JSON file (`data/users.json`).
*   **Security**: Passwords are hashed using `SHA-256` (Note: suitable for demo, production should use bcrypt/argon2).
*   **Operations**: Supports creating users, validating credentials, and retrieving profiles.

### 2. API Routes (`app/api/auth/*`)
*   **Login**: Validates credentials updates a generic HTTP-only cookie (`auth_session`).
*   **Signup**: Creates a new user entry and logs them in.
*   **Logout**: Destroys the session cookie.
*   **Me**: Returns the currently logged-in user profile based on the session cookie.

### 3. Frontend Context (`lib/auth-context.tsx`)
*   **State**: `user` (profile object) and `loading` (boolean).
*   **Persistence**: Checks `/api/auth/me` on initial load to restore session.
*   **Methods**: Exposes `login`, `signup`, `logout` functions to components.

## 🛒 Shopping Cart System

The cart is a completely client-side feature with local persistence.

### Logic (`lib/cart-context.tsx`)
*   **State**: Array of `CartItem` objects `{ productId, quantity, price }`.
*   **Persistence**: Uses `localStorage` to save the cart state, so it survives page reloads.
*   **Hydration**: Uses a `useEffect` to load data only on the client to avoid hydration mismatches with server-rendering.
*   **Calculations**: Automatically calculates `cartCount` and `subtotal`.

## 📦 Data Management

### Products
*   **Source**: Static data in `lib/products.ts` and `lib/mock-data.ts`.
*   **Structure**: Products are defined as constant arrays. This simulates a database but ensures fast, reliable data for the UI without needing a running database server.

### Users
*   **Source**: `data/users.json`.
*   **Behavior**: The file is automatically created if it doesn't exist. It acts as a persistent database for the local environment.

## 🎨 Styling & Design System

*   **Tailwind CSS**: Used for 99% of styling.
*   **RTL Support**: The project is native Arabic.
    *   `dir="rtl"` is set in the root layout.
    *   Tailwind logical properties (e.g., `ms-4`, `pe-2`) should be used instead of physical (`ml-4`, `pr-2`) to ensure correct flipping.
*   **Fonts**: Uses `Noto Sans Arabic` (configured in `app/layout.tsx`).
